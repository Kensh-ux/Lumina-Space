# 窗畔 · 工作台整合版

> 版本：2026-10-31 · 纯前端 · 无构建步骤 · 数据只保存在本机浏览器
> **已接入 Lumina-Space v2.0.0 双模式**：从简易模式设置里的「转换模式」进入 `/room/`；本页设置里有「回到简易模式」。线上静态托管不需要运行 `启动.py`。

打开后是一间可以互动的窗边房间：十八种窗外光景、三十一件陈设、唱片与环境声。房间之上叠加了原 Lumina-Space 的工作台——待办、笔记、番茄钟、等级、规划师与情绪记录；茶几旁另立着一枚黄铜浑天仪，点开可以从三扇门进入星潮、林间小屋与余晖。

---

## 1. 打开方式

**不要直接双击 `index.html`。** 三个世界和音乐需要 HTTP 环境，`file://` 下会被浏览器拦截。

1. 确认电脑已安装 Python 3.8 或更新版本。
2. 在本文件夹里双击 **`启动.py`**。
3. 脚本会在 `127.0.0.1` 上启动本地服务器，自动选择 `8770` 之后的空闲端口，并打开默认浏览器。
4. 启动时会顺带扫描 `assets/music`，把曲名写进 `library.json`；往文件夹里加歌后重开一次脚本即可。
5. 关闭时回到启动窗口按 `Ctrl+C`，或直接关闭窗口。

可选参数：

```bash
python 启动.py --port 8770      # 指定起始端口
python 启动.py --no-browser     # 只启动服务器，不自动开浏览器
```

> 换端口等于换了一个站点，浏览器会把数据当成新的一份。日常使用尽量固定同一个地址。

## 3. 工作台

### 待办

新建时可填标题、描述、优先级、截止日期与时间。支持「未完成 / 全部 / 已完成」筛选、搜索、行内完成、编辑与删除；逾期任务会单独标出。

### 笔记

多页面笔记，输入自动保存，可新建、切换、重命名与删除（至少保留一页）。字数与保存状态显示在底部。

### 番茄钟与等级

- 顶部圆盘可直接开始 / 暂停；用时可选 15、25、45、60 分钟，也可以在「专注」面板里自定义创作、休息与长休的分钟数（1–480），点「应用」或按回车生效。
- 休息默认 5 分钟，长休默认 15 分钟；自定义的休息和长休时长会同时用于圆盘上的休息阶段。
- 每完成第 4 个创作时段进入一次长休息。
- 只有**自然走完**的创作时段才计入专注记录；手动「跳过」不计入，也不会升级。
- 每累计 4 个专注时段升一级。等级与进度显示在圆盘上方。
- 刷新页面后计时器回到待开始，但已完成的专注记录会保留。

### 规划师

按月查看任务，箭头切换月份，点某一天下的「+」可直接为那天建任务，点任务前的圆点即可完成。

### 情绪记录

22 个情绪词或自定义情绪、−724 到 597 的好感值刻度、事件正文，支持搜索、按日期置顶、编辑与删除。**情绪记录只记录心情，不联动房间场景**：场景始终以窗畔自己的光景选择为准。

### 设置

- 自动开始休息 / 自动开始创作两个开关。
- 导出 JSON：包含任务、情绪记录、专注记录、笔记与专注偏好。
- 导入 JSON：恢复任务、情绪、专注记录与笔记；**不会覆盖本机当前的专注偏好**。
- 可单独清空专注记录，或清空整个工作台数据（不影响房间陈设与光景）。

## 4. 三界之门

桌面端点茶几右侧的黄铜浑天仪，手机端从右下角「工作台」→「世界」，会打开「请选择不同的世界」：

| 世界 | 原项目 |
|---|---|
| 星潮 · ASTRAL TIDE | `_天马行空` |
| 林间小屋 · A Cabin in the Woods | `_建模` |
| 余晖 · AFTERGLOW | `_宇宙\余晖_Afterglow_2026-10-29` |

三个世界以整屏 iframe 载入，互相独立。进入时窗畔暂停渲染、环境声与唱片；点左上角「回到窗畔」后，房间从原机位继续，声音恢复。世界首次载入需要几秒钟，遮罩会一直保留到文档真正就绪；超过 25 秒仍慢时会提示可以先回房间。

## 5. 数据与存储

所有数据只在本机浏览器，没有账号、后端或联网请求。

| 键 / 库 | 内容 |
|---|---|
| `lumina:data` | 任务、情绪记录、专注记录、自定义背景等 |
| `lumina:notes` | 工作台笔记页面 |
| `lumina:focus` | 番茄钟偏好与循环计数 |
| `lumina:theme` | 当前房间主题镜像 |
| `lumina:workbench.layout` | 待办 / 笔记窗口的位置、折叠与显隐 |
| `windowlight.music.v1` / `.current` | 唱片列表元数据与当前唱片 id |
| `windowlight.music.hidden` | 从「曲库」里移走的文件名，恢复曲库时清空 |
| IndexedDB `windowlight-music` / `blobs` | 用户导入的音频 Blob |

- 清浏览器站点数据会连同工作台一起清空，建议先用「导出 JSON」备份。
- 导入的音频只存在当前浏览器，不会写进交付文件夹。
- `assets/music` 里的曲目由 `启动.py` 在启动时扫描并写入 `assets/music/library.json`，唱片柜直接读取这份清单；往文件夹里加歌后重开一次即可。公开部署请换成有授权的音乐，或让访客自行导入。

- 曲目下载自网易云音乐（NetEase Cloud Music），版权归原作者及相应权利人所有。

## 6. 目录

```text
04_待办任务整合/
├─ index.html              # 唯一入口：房间 + 工作台
├─ 启动.py                 # 本地静态服务器（扫描 assets/music、无缓存、自动开浏览器）
├─ README.md
├─ assets/                 # 窗畔样式、贴图、音乐（music/library.json 由启动脚本生成）
├─ src/                    # 房间场景、陈设、声音、UI、桥接、三界信物
├─ workbench/              # 工作台的数据层、界面、样式、三个世界的加载器
│  ├─ core.js              # 无 DOM 依赖的数据层，可在 Node 里直接测试
│  ├─ workbench.js         # 待办 / 笔记 / 番茄钟 / 规划师 / 情绪记录 / 设置
│  ├─ worlds.js            # 世界选择层与 iframe 生命周期
│  └─ thumbs/              # 三张世界缩略图
├─ worlds/                 # 星潮、林间小屋、余晖（原样拷贝，可独立打开）
├─ vendor/                 # Three.js 与后期处理脚本
└─ docs/LUMINA-BRIDGE.md   # 窗畔的 iframe 嵌入协议（普通使用不需要读）
```

三个世界保留各自完整的目录与入口，删掉 `worlds/` 只会少掉三扇门，不影响窗畔与工作台。

## 8. 已知限制

- **必须用本地 HTTP 打开**；`file://` 下三个世界会显示提示页。
- 手机端能打开房间与三个世界，但 WebGL 场景较重，建议桌面使用。
- 计时器不跨刷新继续；只有完整走完的创作时段会进入记录。
- 导入 JSON 不覆盖专注偏好，这是有意的：避免备份文件改掉当前设备的习惯设置。
- 场景与情绪记录不联动；工作台也不会读取或改写窗畔的光景选择。
- 换端口即换浏览器站点，`localStorage` 不会跟随。

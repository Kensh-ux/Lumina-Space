# 林间 3D 小屋 · 使用说明

- 版本：`v01-2026-10-28`
- 交付日期：2026-10-29
- 风格：低模手作质感 + 电影级后处理
- 运行方式：普通静态页面，双击 `index.html` 即可

## 一、一句话介绍

一座建在林间空地上的原木小屋：门前石头上坐着读书的小人，四季在雨、雪、晴、黄昏之间切换。下雪时地面、树冠、屋顶会逐渐积雪，点一下空地可以堆一个戴水桶帽的雪人。

引擎不引用任何外部 3D 模型、HDR 或贴图；木纹、瓦片、石墙、草地、白桦树皮、书页、路牌文字全部是运行时用 Canvas 生成的程序化贴图。

## 三、运行

直接双击 `index.html` 即可，无需安装依赖。

three.js 使用 r149 UMD，通过 CDN 加载：

```text
https://cdn.jsdelivr.net/npm/three@0.149.0/build/three.min.js
```

离线运行时，把该文件下载到项目内（例如 `vendor/three.min.js`），并把 `index.html` 里的 script 地址改成本地路径即可。

## 四、操作

| 操作 | 效果 |
| --- | --- |
| 顶部「晴天 / 落雨 / 下雪 / 黄昏」 | 切换四景，颜色、光照、后处理全部插值过渡 |
| 键盘 `1` `2` `3` `4` | 同上，快捷键切景 |
| 拖动画面 | 环视小屋（俯仰有限制） |
| 滚轮 | 拉近 / 拉远 |
| 鼠标移动 | 轻微视差 |
| 下雪时点击空地 | 放一个雪人；最多 12 个，放不下会有提示 |
| 「清空」 | 清除全部雪人 |

雨伞、厚衣服、书本、眼镜、围巾、杯子、书堆、路牌、倒木与树桩都是常驻细节；雨雪天的衣物与道具有各自状态。

## 五、四景差异

| 场景 | 光影 | 环境 | 小人 |
| --- | --- | --- | --- |
| 晴天 | 暖色主光 + 冷色补光 + 林隙体积光 | 蓝天、薄云、远山、草地野花、蝴蝶、鸟 | 薄长袖，读书 |
| 落雨 | 低照度、冷灰调、窗灯与门灯暖光 | 雨丝、湿地、雾、烟囱白烟 | 撑深青雨伞穿黄雨衣 |
| 下雪 | 冷白高调、柔光 | 渐进积雪（地面/树冠/屋顶）、飘雪、雪人 | 绿色毛线帽 + 红围巾厚衣 |
| 黄昏 | 低角度暖橙主光、紫蓝阴影、强分离色调 | 橘色天空、萤火虫、窗灯全开、体积光 | 安静读书，暖边光 |

## 六、引擎 API

`engine/cabinScene.js` 以经典脚本运行，注册 `window.CabinSceneEngine`：

```html
<script src=".../three.min.js"></script>
<script src="./engine/cabinScene.js"></script>
<script>
  const scene = CabinSceneEngine.createCabinScene(canvas, {
    THREE: window.THREE,
    weather: 'sunny',          // sunny | rain | snow | dusk
    quality: 'auto',           // auto | low
    onReady(stats) {},
    onError(error) {},
    onNotice(message) {},
    onSnowmanCountChange(count) {}
  });

  scene.setWeather('snow');
  scene.placeSnowman(2.4, 3.1); // 世界坐标 x, z
  scene.clearSnowmen();
  scene.getStats();
  scene.advance(2);             // 后台标签页验收用：手动推进 2 秒并出帧
  scene.captureFrame('png');    // 需 preserveDrawingBuffer: true
  scene.dispose();
</script>
```

`getStats()` 返回：

```js
{
  weather, ready, fps, width, height, dpr,
  drawCalls, triangles, snowCover, snowmen,
  maxSnowmen, quality, reducedMotion
}
```

### 渲染实现

- 自建 HDR 后处理链：HalfFloat 渲染目标 → 亮部提取 → 1/4 分辨率可分离高斯模糊 → ACES 色调映射 → god rays → 暗角 → 胶片颗粒 → 饱和度/对比度 → 阴影/高光分离色调 → 负片提黑 → 手动 sRGB。
- 主光、补光、轮廓光三点布光；阴影贴图 2048²，PCFSoft。
- 天气通过数值与颜色双通道阻尼插值，切换不重建场景。
- 静态几何按材质合并；草、落叶、远树、雪人部件使用 InstancedMesh；雪人按 6 个部件批次共享，最多 12 个。
- 支持 `prefers-reduced-motion`、页面隐藏时暂停 rAF、DPR 上限 1.5、`quality: 'low'` 降级。

## 七、Lumina-Space 兼容

`integration/lumina/` 里是**不改 Lumina 现有依赖**的包装：

1. 把 `CabinScene.tsx` / `CabinScene.module.css` 复制到 `src/app/`；
2. 把 `engine/cabinScene.js` 复制到 `public/cabin/cabinScene.js`；
3. 用 `<CabinScene weather="sunny" />` 替换 Stage 里的 `MoodScene`（或并排使用）；
4. 需要点击堆雪人时加 `interactive`。

包装只接收 props 和 ref，不导入 mood 类型、不读业务 store，也不修改全局样式。默认从 CDN 加载 three，因此**没有新增 npm 依赖**；离线部署方式见 `integration/lumina/README.md`。

## 八、性能与兼容

- 约 9.0–9.3 万三角形，164–202 draw call（按天气）。
- 桌面集显目标 60fps；测试环境为隐藏标签页，未取得可信真实帧率。
- 支持 WebGL2；WebGL1 会走降级路径。
- 适配窄屏：UI 与相机距离会随容器尺寸收缩。

## 九、已知限制

1. Lumina 包装尚未在 Lumina 工程内跑 `tsc -b`（该目录没有 `node_modules`），接入后建议跑一次 `npm run check`。
2. 4K/超高 DPR 屏未验证；引擎 DPR 上限为 1.5，若需要更锐利可自行调高并复测性能。
3. 雪人只提供点击放置与清空，不支持拖拽移动或删除单个雪人。
4. 场景无音效；雨声/风雪声可按需接入 Lumina 的音频系统。

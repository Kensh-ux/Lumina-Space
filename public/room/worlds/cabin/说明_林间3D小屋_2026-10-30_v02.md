# 林间 3D 小屋 · 使用说明

- 版本：`v02-2026-10-30`
- 交付日期：2026-10-30
- 风格：低模手作质感 + 电影级后处理
- 运行方式：普通静态页面，双击 `index.html` 即可

## 一、一句话介绍

一座建在林间空地上的原木小屋：门前石头上坐着读书的小人，四季在雨、雪、晴、黄昏之间切换。点一下小人，他会按当前天气和你说话；每第十次会给出彩蛋。下雪时地面、树冠、屋顶会逐渐积雪，点一下空地可以堆一个戴水桶帽的雪人。环境声全部由浏览器实时合成，可一键静音。

测试报告与截图不在交付目录内，位置见第十三节。

## 三、运行

直接双击 `index.html` 即可，无需安装依赖。

three.js 使用 r149 UMD，通过 CDN 加载：

```text
https://cdn.jsdelivr.net/npm/three@0.149.0/build/three.min.js
```

离线运行时，把该文件下载到项目内（例如 `vendor/three.min.js`），并把 `index.html` 里的 script 地址改成本地路径即可。环境声由 Web Audio 生成，不需要额外的音频资源或网络请求。

## 四、操作

| 操作 | 效果 |
| --- | --- |
| 顶部「晴天 / 落雨 / 下雪 / 黄昏」 | 切换四景，颜色、光照、后处理与声场全部插值过渡 |
| 键盘 `1` `2` `3` `4` | 同上，快捷键切景 |
| 点击小人 | 按当前天气说下一句；每第 10 次点击是彩蛋 |
| 右上角声音按钮 | 开启 / 静音程序化环境声；首次点击页面前会显示待启动状态 |
| 拖动画面 | 环视小屋（俯仰有限制） |
| 滚轮 | 拉近 / 拉远 |
| 鼠标移动 | 轻微视差 |
| 下雪时点击空地 | 放一个雪人；最多 12 个，放不下会有提示 |
| 「清空」 | 清除全部雪人 |

拖动画面不会触发对话；只有点击小人（且指针没有明显位移）才会说话。下雪时点击空地只会放雪人，不会误触小人。

## 五、四景差异

| 场景 | 光影 | 环境 | 小人 | 环境声 |
| --- | --- | --- | --- | --- |
| 晴天 | 暖色主光 + 冷色补光 + 林隙体积光 | 蓝天、薄云、远山、草地野花、蝴蝶、鸟 | 薄长袖，读书 | 松林风、叶隙沙沙、远处鸟鸣 |
| 落雨 | 低照度、冷灰调、窗灯与门灯暖光 | 雨丝、湿地、雾、烟囱白烟 | 撑深青雨伞穿黄雨衣 | 雨幕、滴水、极低频闷雷 |
| 下雪 | 冷白高调、柔光 | 渐进积雪（地面/树冠/屋顶）、飘雪、雪人 | 绿色毛线帽 + 红外套，围巾与绒球 | 低通风声、落雪闷响 |
| 黄昏 | 低角度暖橙主光、紫蓝阴影、强分离色调 | 橘色天空、萤火虫、窗灯全开、体积光 | 安静读书，暖边光 | 蟋蟀、极轻的篝火噼啪 |

雨伞、厚衣服会随天气出现；书本、眼镜、围巾、杯子、书堆、路牌、倒木与树桩一直都在。

## 六、和小人说话

- 每个天气有 3–4 句台词，按点击顺序循环；切景后再点会从该天气自己的台词组继续。
- 气泡停留时间按文本长度约为 5.2–9 秒；再次点击会刷新计时。
- 切换天气会立即收起当前气泡，避免台词和天气对不上。
- 每第 10 次点击（跨天气累计）会插播两句彩蛋台词，停留约 9 秒；第 11 次恢复正常台词。
- 台词触发时，如果环境声正在运行，会有一小段两三个音符的轻提示音；静音时提示音也静音。
- 气泡使用 `role="status"`、`aria-live="polite"`，显示时从 `aria-hidden="true"` 切到 `false`，读屏器可以读到新台词。

台词原文在 `engine/cabinScene.js` 顶部的 `TALK_LINES` 和 `TALK_EGG` 常量里，改文案不需要碰渲染代码。

## 七、环境声

环境声是一套**程序化混音**，没有 mp3/ogg：

- 粉红噪声经过不同滤波和音量包络，分别合成风、叶隙、雨幕、低频闷雷和雪声；
- 正弦 / 三角波合成鸟鸣、滴水、蟋蟀和提示音；
- 四景有各自的混音表，切换天气时用 `setTargetAtTime` 平滑过渡，不会硬切；
- 主输出经过一个轻压缩器（threshold -20 dB，ratio 3），默认总音量 0.62。

浏览器不允许网页在用户交互前自动出声，所以：

1. 首次点击画面或按键盘后，音频图才真正建立并尝试 `resume()`；
2. 在第一次手势之前，声音按钮显示「待启动」；
3. 点声音按钮可以随时静音 / 恢复；静音只把主增益拉到 0，不销毁音频图，恢复时没有重新加载成本；
4. 浏览器不支持 Web Audio 时，`supported` 为 `false`，场景其余部分照常运行。

演示页默认开声；加 `?sound=0` 可以默认静音启动。Lumina 包装默认静音，由使用方显式打开。

## 八、引擎 API

`engine/cabinScene.js` 以经典脚本运行，注册 `window.CabinSceneEngine`：

```html
<script src=".../three.min.js"></script>
<script src="./engine/cabinScene.js"></script>
<script>
  const scene = CabinSceneEngine.createCabinScene(canvas, {
    THREE: window.THREE,
    weather: 'sunny',          // sunny | rain | snow | dusk
    quality: 'auto',           // auto | low
    reducedMotion: undefined,  // 不传则跟随系统
    preserveDrawingBuffer: false,
    sound: true,               // 是否需要环境声
    volume: 0.62,              // 0–1
    speechBubble: true,        // false 时不创建对话气泡
    onReady(stats) {},
    onError(error) {},
    onNotice(message) {},
    onSnowmanCountChange(count) {},
    onPersonTalk(event) {},
    onAudioStateChange(state) {}
  });

  scene.setWeather('snow');
  scene.placeSnowman(2.4, 3.1); // 世界坐标 x, z
  scene.clearSnowmen();
  scene.getStats();
  scene.talk();                 // 返回本次台词详情
  scene.hideSpeech();
  scene.setSoundEnabled(false);
  scene.toggleSound();
  scene.getAudioState();
  scene.advance(2);             // 后台标签页验收用：手动推进 2 秒并出帧
  scene.captureFrame('png');    // 需 preserveDrawingBuffer: true
  scene.dispose();
</script>
```

### 常用方法

| 方法 | 说明 |
| --- | --- |
| `setWeather(name)` | 切景；内部插值，不重建场景 |
| `getWeather()` | 当前目标天气 |
| `placeSnowman(x, z)` | 在雪天放置雪人，返回是否成功 |
| `clearSnowmen()` / `getSnowmanCount()` / `getSnowmen()` | 清空、计数、取位置列表 |
| `talk()` / `getTalkCount()` / `hideSpeech()` | 说话、累计点击次数、立即收起气泡 |
| `setSoundEnabled(bool)` / `toggleSound()` / `isSoundEnabled()` | 环境声开关 |
| `setVolume(0–1)` / `getAudioState()` | 音量与音频状态 |
| `advance(seconds)` / `captureFrame(type)` | 验收辅助：推进动画、取 data URL |
| `dispose()` | 释放 WebGL、音频、DOM 气泡与事件监听 |

`talk()` 返回：

```js
{
  text: '有人让我坐在这里，晒太阳',
  weather: 'sunny',
  clicks: 1,
  easterEgg: false,
  lines: null            // 彩蛋时是两句台词的数组
}
```

`getStats()` 返回：

```js
{
  weather, ready, fps, width, height, dpr,
  drawCalls, triangles, snowCover, snowmen,
  maxSnowmen, quality, reducedMotion
}
```

`getAudioState()` 返回：

```js
{ supported, enabled, running, weather, volume }
```

`enabled` 是使用方是否要求开声，`running` 是 AudioContext 是否真的在运行；首次手势之前通常是 `enabled: true, running: false`。

## 九、演示页可选参数

这些参数只影响演示页，方便截图或验收：

| 参数 | 作用 |
| --- | --- |
| `weather=sunny\|rain\|snow\|dusk` | 启动天气 |
| `ui=0` | 隐藏页面 UI 和压暗层，只留场景 |
| `sound=0` | 演示页默认静音启动 |
| `quality=low` | 关闭阴影、DPR 压到 1 |
| `motion=0` | 强制 reduced motion（停掉雨雪飘动等） |
| `snowmen=0–12` | 启动后预置雪人数量 |
| `talk=1–20` | 启动后自动说 N 次，用于截对话 |
| `talkdelay=毫秒` | 自动对话的首次延迟，默认 900 |
| `debug=1` | 显示左下角渲染统计浮层 |
| `capture=1` | 开启 `preserveDrawingBuffer`，供 `captureFrame` 截图 |

## 十、渲染实现

- 自建 HDR 后处理链：HalfFloat 渲染目标 → 亮部提取 → 1/4 分辨率可分离高斯模糊 → ACES 色调映射 → god rays → 暗角 → 胶片颗粒 → 饱和度/对比度 → 阴影/高光分离色调 → 负片提黑 → 手动 sRGB。
- 主光、补光、轮廓光三点布光；阴影贴图 2048²，PCFSoft。
- 天气通过数值与颜色双通道阻尼插值，切换不重建场景。
- 静态几何按材质合并；草、落叶、远树、雪人部件使用 InstancedMesh；雪人按 6 个部件批次共享，最多 12 个。
- 语音气泡定位在每帧把头顶锚点投影到屏幕坐标，再做左右边界收拢和上下翻转。
- 支持 `prefers-reduced-motion`、页面隐藏时暂停 rAF、DPR 上限 1.5、`quality: 'low'` 降级。

## 十一、Lumina-Space 兼容

`integration/lumina/` 里是**不改 Lumina 现有依赖**的包装：

1. 把 `CabinScene.tsx` / `CabinScene.module.css` 复制到 `src/app/`；
2. 把 `engine/cabinScene.js` 复制到 `public/cabin/cabinScene.js`；
3. 用 `<CabinScene weather="sunny" />` 替换 Stage 里的 `MoodScene`（或并排使用）；
4. 需要点击小人或堆雪人时加 `interactive`；背景场景建议保持 `false`，避免画布吃掉页面滚动和按钮事件；
5. 环境声默认关闭，需要时加 `sound`；浏览器会在第一次交互后才真正出声。

包装只接收 props 和 ref，不导入 mood 类型、不读业务 store，也不修改全局样式。默认从 CDN 加载 three，因此**没有新增 npm 依赖**；离线部署方式见 `integration/lumina/README.md`。

新增的包装能力：`speechBubble`、`sound`、`volume`、`onPersonTalk`、`onAudioStateChange`，以及 ref 上的 `talk()`、`getTalkCount()`、`hideSpeech()`、`setSoundEnabled()`、`toggleSound()`、`isSoundEnabled()`、`getAudioState()`。

## 十二、性能与兼容

- 约 9.1–9.3 万三角形；1280×800、DPR 1 时约 164–211 draw call（`low` 约 164，四景自动模式约 180–211，雪人越多 draw call 越高）。
- 桌面集显目标 60fps；自动化环境为无头浏览器，未取得可信的真实 GPU 帧率。
- 支持 WebGL2；WebGL1 会走降级路径。
- 已验 `quality=low`（`quality: low`、DPR 1、164 draw call）与 `motion=0`（`reducedMotion: true`）。
- 适配窄屏：UI 与相机距离会随容器尺寸收缩；交互按桌面鼠标/触控板设计，没有做双指缩放。

## 十三、已知限制

1. Lumina 包装尚未在 Lumina 工程内跑 `tsc -b`（该目录没有 `node_modules`），接入后建议跑一次 `npm run check`。
2. 4K/超高 DPR 屏未验证；引擎 DPR 上限为 1.5，若需要更锐利可自行调高并复测性能。
3. 雪人只提供点击放置与清空，不支持拖拽移动或删除单个雪人。
4. 环境声的音色与混音只在无头浏览器里验证了 Web Audio 状态，没有经过真实扬声器试听；实际音量以现场为准。
5. 对话气泡被追加到 `document.body`，使用全局 `.cabin-speech` 类；在 Lumina 中如果页面有自己的高 z-index 浮层，气泡可能被盖住，必要时调整该类的 `z-index`。
6. 背景场景开启 `interactive` 会接管整个 canvas 的指针事件，可能影响 Lumina 的滚动；这是 WebGL 交互的固有取舍。
7. 移动端未做双指缩放，只有单指拖动和鼠标滚轮。

### 4.5 情绪逻辑

`src/features/mood/mood.ts`：

```ts
import type { MoodId } from '../../lib/types';

export type { MoodId } from '../../lib/types';

export interface MoodMeta {
  id: MoodId;
  label: string;
  emoji: string;
  description: string;
}

export const MOODS: readonly MoodMeta[] = [
  { id: 'positive', label: '积极', emoji: '☀️', description: '明亮、温暖' },
  { id: 'neutral', label: '中性', emoji: '🌤️', description: '平稳、安静' },
  { id: 'negative', label: '消极', emoji: '🌧️', description: '低饱和、安静' },
] as const;

export const DEFAULT_MOOD: MoodId = 'neutral';

export function isMoodId(value: unknown): value is MoodId {
  return value === 'positive' || value === 'neutral' || value === 'negative';
}

export function getMoodMeta(id: MoodId): MoodMeta {
  const found = MOODS.find((m) => m.id === id);
  return found ?? MOODS[1];
}
```

`src/lib/types.ts`：

```ts
export type MoodId = 'positive' | 'neutral' | 'negative';

export interface Task {
  id: string;
  title: string;
  done: boolean;
  createdAt: string;
  completedAt: string | null;
}

export interface AppDataV1 {
  schemaVersion: 1;
  tasks: Task[];
  mood: {
    current: MoodId;
    updatedAt: string;
  };
}
```

`src/features/mood/useMood.ts`：

- 从 `../../lib/types` 取 `AppDataV1`，从 `./mood` 取 `DEFAULT_MOOD` / `isMoodId`，从 `../../lib/storage` 取 `loadData` / `saveData`。
- `useState<AppDataV1>(() => loadData())`。
- `useEffect` 把 `data.mood.current` 写到 `document.documentElement.dataset.theme`。
- `useEffect` 在 `data` 变化时 `saveData(data)`；失败时把 `storageError` 置 true。
- `setMood(next)` 更新 `mood.current` 和 `updatedAt`。
- **本卡要求**实现一个仅开发/截图用的预览参数：`import.meta.env.DEV` 下读取 `?theme=`，只改 `data-theme`，不写存储；生产构建不生效。这是为了让 4.9 的三张截图可重复，不算产品功能。

### 4.6 存储 adapter

`src/lib/storage.ts`：

```ts
const KEY = 'lumina:data';
const BACKUP_KEY = 'lumina:data:backup';

export function createDefaultData(): AppDataV1 { /* schemaVersion: 1, tasks: [], mood: neutral */ }
export function loadData(storage: Storage = localStorage): AppDataV1 { /* try parse + validate; 失败先备份再回默认 */ }
export function saveData(data: AppDataV1, storage: Storage = localStorage): boolean { /* 失败返回 false，不抛 */ }
export function clearData(storage: Storage = localStorage): void { /* 只删自己的键 */ }
```

容错规则：

- JSON 解析失败、`schemaVersion !== 1`、`tasks` 不是数组、`mood.current` 非法 → 把原始字符串写入 `BACKUP_KEY`，返回默认值。
- 读取/写入异常（隐私模式、配额）→ 捕获，`saveData` 返回 false，不崩。
- 不删除非 `lumina:*` 的键。
- 时间用 `new Date().toISOString()`。

`src/app/App.tsx`：

- 接收 `mood`，外层带 `data-mood`；用 CSS 渐变 + 简略场景元素（太阳 / 云 / 雨线，`aria-hidden`）。

- 固定在左下角，垂直 rail：今日 / 专注 / 设置；点击展开上方 panel。

## 9. 风险与备注

| 风险 | 处理 |
|---|---|
| Vite 模板版本变化，脚本/tsconfig 结构不同 | 以 `npm run check` + `npm test` 能跑通为准；回执写实际命令 |
| `tsc -b` 因 project references 报错 | 改用 `tsc -p tsconfig.app.json --noEmit`，并在回执说明 |
| jsdom 没有 `crypto.randomUUID` | 本卡不创建任务，暂不需要；002 再处理 |
| dev server 在 WSL，Windows 访问不到 | 加 `--host 0.0.0.0`；仍不行就查 WSL 端口转发 |
| 截图是空白/半截 | 增加 `--virtual-time-budget`，确认 HTTP 200 再截 |
| 主题切换闪屏 | 过渡只加在颜色属性；首次渲染前设置 `data-theme`（可在 `index.html` 内联一行脚本） |
| 侧边栏遮挡主内容 | 1280×800 下 rail 宽度 ≤ 64px，panel 浮层不挤压主区；窄屏折叠 |
| 侧边栏面板焦点丢失 | 打开 panel 后焦点留在触发按钮或移入 panel；Esc 关闭；`aria-expanded` 同步 |
